# BERIAS Training 2.1

Live: https://berias2025.github.io/meal-prep-app/training/

Buildless German training PWA: strength, aerobic conditioning, evening mobility, editable and archivable exercise library, conservative interval progression and full JSON backup/restore. Open this URL in Android Chrome and select Add to Home screen > Install. Wait for Offline bereit.

Data stays in localStorage on the device; no account, analytics, sync, or personal logs are shipped. Back up on the old site before moving; browser storage does not move between addresses. Restore the full backup in Settings, then review the new plan if restoring a legacy plan. Never clear the old data before checking the restored records.

Source is this directory. Publishing a change to main runs the existing GitHub Pages workflow. The meal planner remains at the site root.
